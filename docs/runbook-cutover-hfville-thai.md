```

รบกวนทดสอบดังนี้:
1. เปิดระบบใหม่ (Web App) เลือกสาขา "HF Ville"

3. ดูว่าข้อมูลปรากฏถูกต้องหรือไม่ (ห้องพัก, ลูกค้า, การจองวันนี้)

ถ้าทุกอย่างปกติ ตอบ "OK" กลับมาได้เลยค่ะ/ครับ
ถ้ามีอะไรผิดปกติ ตอบ "มีปัญหา" แล้วบอกอาการ จะ rollback ทันที
```

## หมายเหตุสำคัญ

- **ระบบเดิม (.NET) ไม่ได้ถูกแตะ** — ทำงานได้ปกติทั้งก่อน ระหว่าง และหลังอัพเดท
- **Database (HOTEL บน <ville-db-host>)** ไม่ได้ถูกแก้ — เพิ่ม Change Tracking ไปแล้วเมื่อ 2026-04-29 ได้ทดสอบเรียบร้อย
- **Maintenance window จริงๆ ใช้เวลาแค่ ~30 วินาที** ที่เหลือคือเวลาเผื่อการประสานงาน + ทดสอบ

## Glossary (ถ้าฝ่ายต้อนรับถาม)

| ภาษาอังกฤษ | คำอธิบายภาษาไทย |
|---|---|
| Cutover | สลับระบบใหม่ |
| Shadow mode | ทำงานเงาๆ — อ่านข้อมูลแต่ไม่บันทึก (ทดสอบก่อนใช้จริง) |
| Real-time sync | ข้อมูลอัพเดททันที |
| Change Tracking | ระบบติดตามการเปลี่ยนแปลงในฐานข้อมูล |
| WireGuard / WG | VPN ที่เชื่อม HQ กับ HF Ville (ทดแทนระบบเดิม) |
| Rollback | กลับไปใช้ระบบเดิม (ถ้าระบบใหม่มีปัญหา) |
